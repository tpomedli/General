# Recipe Book

A personal recipe book. The first page lists every recipe. The plus in the top right opens a form for the title, author, ingredients, and directions.

Recipes are stored in [`data/recipes.json`](data/recipes.json). Each saved recipe keeps the title, author, ingredients, directions, and the signed-in person it belongs to. Share on a recipe sends that write-up.

```bash
npm install
npm run dev
```
